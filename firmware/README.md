# Firmware

Firmware source will be published here as development proceeds.

Intended target: Waveshare ESP32-S3 Mini / ESP32-S3-Zero-class board,
2.8-inch 240 × 320 SPI resistive touchscreen and internal SPI microSD module.
The exact wired module variants and pin allocation still require verification.

Planned areas: display/touch bring-up, BLE transport, a versioned navigation
message interface, UI state/rendering, settings, assets and storage.
No working firmware implementation is included in this initial release.
