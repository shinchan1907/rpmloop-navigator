# Hardware

The current hardware release is the P3 enclosure fit-test package in
[`printing_files/`](../printing_files/).

It includes the editable SolidCraft model, STEP files, individual STL parts,
source generators, images and documented verification limits. Electrical
schematics, a verified wiring/pin map and battery circuitry are not part of
this initial release. Reserved battery/GPS volumes are design allowances.
